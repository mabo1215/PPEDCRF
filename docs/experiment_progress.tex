\paragraph{Current execution state.} The new public-data adapters and unary
attribution validator are now present in \texttt{src/scripts/}. Their local
CUDA smoke tests are required before any data transfer. The MSLS and KITTI-360
files are not yet present locally; both official releases require registration
or intended-use approval. The previous vGPU 3090 instance was shut down, so no
remote run is currently active.

\paragraph{Evidence policy.} The existing 12/50-pair benchmark remains a
visual-similarity proxy. E1 is the only route to a true-place/geolocation
claim. E2--E7 can strengthen mechanism, utility, and attacker-sensitivity
claims, but incomplete, smoke, blocked, or protocol-mismatched outputs remain
engineering evidence and must not be inserted into the manuscript.
