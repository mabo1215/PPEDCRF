\paragraph{Current execution state.} The vGPU 3090 instance's \texttt{src/}
checkout was found wiped (only \texttt{.pyc} caches and cached VPR weights
remained; all \texttt{.py} sources were missing) at the start of this
session and has been restored from the local checkout. The full monitoring
image corpus (14\,GB, 25{,}934 files) is being transferred from the local
machine directly to the vGPU instance in the background; the E2 sigma-sweep
screens are launched as soon as the transfer completes. E3/E4/E6/E7 required
no vGPU time and were completed on the local RTX 3070 / CPU from already
-existing per-query exports.

\paragraph{Evidence policy.} The existing 12/50-pair benchmark remains a
visual-similarity proxy. E1 is the only route to a true-place/geolocation
claim. E2--E7 strengthen mechanism, utility, and attacker-sensitivity
claims, but incomplete, smoke, blocked, or protocol-mismatched outputs
remain engineering evidence and must not be inserted into the manuscript.
Every number integrated into \texttt{paper/main.tex} or
\texttt{paper/appendix.tex} in this session was read directly from a
non-smoke run's CSV/JSON export (\texttt{scientific\_evidence} audited
manually where the export script's own flag defaults to false pending
review) and cross-checked against the numbers already cited elsewhere in the
manuscript for consistency.
