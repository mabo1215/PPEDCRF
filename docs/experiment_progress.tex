\paragraph{Current execution state.} Local code changes and the smoke test are
the next critical path. The intended 4c alias is \texttt{h800cs2}, but SSH
currently rejects it because the remote host fingerprint changed. This is a
security gate, not a compute failure: host-key verification must be repaired
or the fingerprint confirmed before any remote launch. The handoff contract
for Claude Code will be written to
\texttt{docs/4c\_experiment\_handoff.md} after the runnable commit is pushed.

\paragraph{Evidence policy.} The existing 12/50-pair benchmark remains a
visual-similarity proxy. E1 is the only route to a true-place/geolocation
claim. E2--E7 can strengthen mechanism, utility, and attacker-sensitivity
claims, but incomplete, smoke, blocked, or protocol-mismatched outputs remain
engineering evidence and must not be inserted into the manuscript.

\paragraph{Scope of this file.} Three tables, kept current rather than
appended to, tracking the PPEDCRF (dynamic-CRF-guided selective
perturbation for background-based location privacy) revision cycle:
\begin{enumerate}
  \item \textbf{Table~\ref{tab:completion}}: current completion status of
  every open item in the active review, \texttt{docs/Revision\_suggestions.tex}.
  \item \textbf{Table~\ref{tab:schedule}}: the next-step experiment
  schedule -- what is running or queued, how much is done, and the
  estimated completion time.
  \item \textbf{Table~\ref{tab:textonly}}: manuscript-text-only revision
  items -- no experiment, GPU run, or scorer required -- with a
  0--100\% completion estimate and, for anything not at 100\%, the
  specific reason in the notes column.
\end{enumerate}
Day-to-day narrative updates live in \texttt{docs/progress.md}.
