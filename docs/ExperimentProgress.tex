\section*{Where This Cycle Stands}

The active review is the ninth independent review in
\texttt{docs/RevisionSuggestions.tex} (10 September 2026, IEEE TIFS, verdict
\emph{minor revision}), findings R1--R6. \textbf{All six are closed.} The
cycle's substance was giving the second dataset the anchor the first one has
had all along: a clean baseline and a white-box power check. Clean Top-1 there
is $0.1498$, the mechanism's own release $0.1512$ --- it moves nothing --- and
a white-box attacker reaches $0.0000$ with a clustered interval excluding zero.
The benchmark can be moved, so its null is a null and not a floor. That was the
one thing a referee could not previously tell.

\paragraph{Compute state.} \textbf{Nothing is running, and no remote host was
used.} 2c (2$\times$RTX~4080 SUPER), vGPU~3090 and PRO~6000 were each checked
for the R5 data and none held it; the data was on the local G: drive, so the
whole cycle ran on the RTX~3070. The R5 arms took about 25 minutes of wall
clock between them, against a measured 7 minutes of pure compute --- the
difference is reading 1408$\times$376 PNGs off an external drive, which is why
moving the job to a faster GPU would have made it slower, not quicker.

\paragraph{Document state.} \texttt{main.pdf} \textbf{13 pages} against the
13-page TIFS ceiling; abstract \textbf{234} words counting each math
expression as one word (window 150--250);
\texttt{supplementary.pdf} \textbf{6 pages}, the SPS ceiling without
Editor-in-Chief approval; \texttt{titlepage.pdf} 1 page; the extended evidence
report, released with the code and not submitted, 12 pages. All four build with
\textbf{0 undefined references, 0 undefined citations and 0 overfull boxes}.
The three reference rows and the audit's second direction were added to
documents already at both ceilings, and paid for: the per-backbone
redistribution table moved to the extended report, which brings the count of
tables living there rather than in the supplement to five. That table showed
five identical columns in every one of six rows --- the sentence that says so
carries the same information in three lines.

\paragraph{Verification state.} \textbf{395 claims verify against raw exports;
0 mismatched, 0 unverifiable, 0 missing from their source file}, up from 333.
The additions this cycle are the second dataset's three reference levels. Two
claims were also \emph{removed}: the label-audit counts had been registered
with recompute functions that returned the printed constants, which verifies
nothing while inflating the total. Recomputing them needs manifest coordinates
the exports do not carry, so they are reproduced by rerunning the manifest
builder instead. \emph{A correction to an earlier statement in
this file:} the auditor does not cover every printed number. It covers every
table cell in both documents plus the registered prose claims; 74 of the 182
distinct three- and four-decimal literals in the manuscript still have no
claim, most of them interval endpoints quoted beside a covered point estimate.

\paragraph{A new check.} \texttt{check\_cross\_document\_refs.py} resolves
every literal \texttt{Table~S$n$} / \texttt{Fig.~S$n$} in the manuscript
against the supplement's actual float order, following \verb|\input| into the
generated tables. This is the class of defect R2 found: LaTeX cannot see a
reference into a separately compiled document, so the build reported zero
undefined references while the manuscript pointed at the wrong table. The
manuscript now carries no literal S-number at all, and the check fails loudly
if one is reintroduced and goes stale.

every pair at least 600 frames (about a minute) apart. Adjacent revisited cells
are merged first --- two cells metres apart are one street corner and, left
separate, generate each other's false negatives. That raised label agreement
from $42\%$ to $100\%$ of the gallery frames within 25\,m. \\
\addlinespace

Honest limit & 16 distinct places behind 227 queries, against 277 behind 400 on
MSLS, and a clean Top-1 of only $0.1498$ to begin with --- the white-box arm is
what shows that is still enough to detect a large effect. This is what R1 turned on: at 14.2 queries per place the clustered
interval is $1.93\times$ wider than the query one and covers zero, so the
direction effect is consistent in sign and size but not separated here. The
allocation null is unaffected --- no placement separates from zero under either
unit. A place is also a road stretch rather than a 25\,m ball, so absolute
Top-1 is not comparable with the MSLS tables. \\

redistribute the gaps, so the declared tolerance is generous on either scale.
